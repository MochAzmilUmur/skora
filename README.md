# Skora – Aplikasi Sistem Uji Kompetensi Online

Skora adalah aplikasi sistem uji kompetensi berbasis web yang dirancang untuk
mendukung pelaksanaan ujian kompetensi secara daring. Aplikasi ini bertujuan
untuk mempermudah proses pengelolaan ujian, mulai dari manajemen pengguna,
penyusunan soal, pelaksanaan ujian, hingga proses penilaian hasil ujian secara
terstruktur dan terintegrasi.

Aplikasi Skora dikembangkan sebagai solusi digital untuk menggantikan proses
uji kompetensi konvensional yang masih dilakukan secara manual, sehingga dapat
meningkatkan efisiensi, akurasi penilaian, serta kemudahan monitoring oleh
asesor maupun pengelola sistem.

## 🎯 Tujuan Aplikasi

Tujuan utama dari pengembangan aplikasi Skora adalah:
- Menyediakan platform uji kompetensi yang terpusat dan mudah diakses
- Mempermudah asesor dalam mengelola soal, peserta, dan hasil ujian
- Memberikan pengalaman ujian yang terstruktur dan transparan bagi peserta
- Mengurangi kesalahan administrasi dan penilaian yang sering terjadi pada
  sistem manual

## 📌 Ruang Lingkup Aplikasi

Aplikasi Skora mencakup beberapa ruang lingkup utama, antara lain:
- Manajemen data pengguna (asesor dan peserta ujian)
- Pengelolaan bank soal dan jawaban
- Pembuatan dan pengaturan sesi atau room ujian
- Pelaksanaan ujian secara online
- Penilaian hasil ujian secara otomatis maupun manual
- Penyajian hasil dan laporan uji kompetensi

## ✨ Fitur Utama

Fitur-fitur utama yang tersedia pada aplikasi Skora meliputi:
- Sistem autentikasi dan otorisasi pengguna
- Manajemen pengguna berdasarkan peran (role)
- Pengelolaan bank soal uji kompetensi
- Pembuatan dan pengaturan room ujian
- Pelaksanaan ujian berbasis web
- Penilaian dan rekapitulasi hasil ujian
- Penyimpanan dan pengelolaan data ujian secara terpusat

## 🛠️ Teknologi yang Digunakan

Aplikasi Skora dikembangkan dengan memanfaatkan beberapa teknologi utama
sebagai berikut:

- **Go (Golang)**  
  Digunakan sebagai bahasa pemrograman backend untuk membangun layanan API
  yang efisien, cepat, dan memiliki performa tinggi dalam menangani proses
  bisnis aplikasi.

- **PostgreSQL**  
  Berperan sebagai sistem manajemen basis data relasional yang digunakan untuk
  menyimpan data pengguna, soal, hasil ujian, serta data pendukung lainnya
  secara terstruktur dan aman.

- **Docker dan Docker Compose**  
  Digunakan untuk melakukan containerization pada aplikasi dan database,
  sehingga memudahkan proses deployment, konfigurasi lingkungan, serta
  menjaga konsistensi sistem di berbagai lingkungan pengembangan.

- **pgAdmin 4**  
  Digunakan sebagai alat bantu berbasis web untuk mengelola dan memantau
  database PostgreSQL secara visual.

- **Git dan GitHub**  
  Digunakan sebagai sistem kontrol versi untuk mengelola kode sumber aplikasi
  serta mendukung kolaborasi dan dokumentasi pengembangan proyek.
